Starting MPF

[cd .\mpf\Scripts]
Open CMD and navigate to "C:\Users\Ryzen\mpf\Scripts>" type "activate"

This should enable mpf. It will now display "(mpf) C:\Users\Ryzen\mpf\Scripts>"

Now navigate to "(mpf) C:\Users\Ryzen\Documents\MikesPinballProject>" and type "mpf -xtb"

-x: Virtual mode (no hardware)
-t: text logging output mode (no UI console)
-b: standalone mode (no media controller)

************

Naviagte to "(mpf) C:\Users\Ryzen\mpf\Scripts>" and type "deactivate"
